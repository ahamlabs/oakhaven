Important limitation
The board is a generated concept infographic, not a production sprite atlas. Some tiny labels and sprite details are illustrative or imperfect. Upscaling improves viewing size but cannot recover detail that was not present in the original image. For exact implementation, use the Oakhaven Character & Asset Bible's stated dimensions, palettes, frame order, filenames, and transparent PNG requirements; create pixel sprites separately at native resolution rather than cropping them from this board.
